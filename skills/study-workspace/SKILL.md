# 学习工作区规范（Study Workspace）

本文件是学习陪跑团的**唯一目录与记录契约**。任何成员在归档资料、记录刷题、写总结前，必须先读本文件并严格遵守。

## 1. 课程根目录的确定

1. 默认使用**当前工作区目录**作为课程根目录。
2. 若用户指定了课程路径（如 `D:/courses/大学物理`），以用户指定为准，并写入 `学习档案.md`。
3. 一个课程根目录对应一门课。用户同时学多门课时，为每门课建独立根目录，不混放。

## 2. 目录结构（固定）

```
{课程根目录}/
  学习档案.md                  # 课程信息、章节进度、掌握度、下次复习时间
  01-课程资料/
    课本/
      原始/                    # 课本原件（PDF/EPUB 等），原样保留，禁止删改
      课本索引.md              # 章节 ↔ 文件 ↔ 锚点 对照表
      {课本名}.md              # 转换后的 Markdown；过大时按章拆分 {课本名}-第01章.md
      assets/                  # 课本抽出的图片，md 中用相对路径引用
    课件/
      第01章-{章名}/
        原始/                  # 本章课件原件（PPT/PDF/Word/图片），原样保留
        {课件名}.md            # 每个原件对应一个同名 .md
        assets/
        本章资料索引.md        # 本章资料清单 + 一句话内容提要 + 覆盖考点
      第02章-{章名}/
  02-刷题记录/
    第01章-{章名}/
      答案/                    # 用户提供的答案/解析原件及其 .md
      {YYYY-MM-DD}-刷题.md     # 当天该章刷题记录，同天追加不新建
    错题本.md                  # 全课程错题汇总（跨章），含复习到期日
  03-总结复盘/
    知识点/
      第01章-{章名}.md         # 本章知识点总结
    解题技巧.md                # 按题型归类，持续追加
    易错点.md                  # 按章节归类，持续追加
    复习计划.md                # 间隔复习队列与完成情况
```

规则：
- 章节文件夹命名统一 `第NN章-{章名}`，NN 两位数字；无章节的资料放 `00-通识与导论`。
- 只新增/追加，**不覆盖、不删除**用户原件与已有记录；确需修订时在文件末尾追加修订说明。
- 同名文件冲突时在文件名后加 `-2`、`-3`，不覆盖。
- 所有路径写进记录时使用相对课程根目录的路径。

## 3. 原件 → Markdown 转换流程

1. **先归档再转换**：原件先复制进对应 `原始/`，再在同一章节目录生成 `.md`。
2. **按格式选工具**（就地可用者优先，缺工具时说明并给出替代方案）：
   - PDF：`workbuddy-pdf` skill 提取文本与表格；扫描版需按页看图识别，公式与图表逐页核对。
   - PPT/PPTX：`python-pptx` 提取每页标题、正文、备注，保留页序；或先转 PDF 再走 PDF 流程。
   - DOC/DOCX：`pandoc` 转 `gfm`，图片用 `--extract-media` 落到 `assets/`。
   - 图片/照片：直接视觉识别转写，公式用 LaTeX。
   - 表格类（XLSX）：转 Markdown 表格，注明来源工作表。
3. **转换质量要求**：
   - 保留原始层级：`#` 章、`##` 节、`###` 小节，标题与原件一致，不自创标题。
   - 公式一律 LaTeX（行内 `$...$`，独立 `$$...$$`），符号不得意译。
   - 表格用 Markdown 表格；图用 `![](assets/xxx.png)` 并在图下写一句图意说明。
   - 每页/每张幻灯片结束插入 `<!-- p.12 -->` 或 `<!-- slide 5 -->` 定位标记，供引用溯源。
   - 识别不清处写 `[待人工核对：原文此处模糊]`，**禁止编造补齐**。
4. **转换后自检**：抽 2-3 处公式/数字与原件比对，确认无误才算完成；未完成核对的在索引里标「未校对」。
5. 更新对应索引文件与 `学习档案.md` 的资料清单。

## 4. 引用出处格式（强制）

任何讲解、解答、总结中出现的知识点，凡来自资料，必须紧跟出处：

```
【出处：01-课程资料/课件/第03章-牛顿定律/第三章课件.md §3.2，slide 7】
【出处：01-课程资料/课本/大学物理.md §4.1，p.58】
```

- 无资料支撑时明确写「资料未覆盖，以下为通用解法/补充知识」，不得伪装成引用。
- 引用前必须真的读过对应文件，禁止凭文件名猜内容。

## 5. 刷题记录模板

`02-刷题记录/第NN章-{章名}/{YYYY-MM-DD}-刷题.md`：

```markdown
# {YYYY-MM-DD} 第NN章 刷题记录

## 题 1
- **题目**：{原文照录，含图则说明图意}
- **来源**：{用户粘贴 / 文件名 / 试卷名}
- **答案依据**：{官方答案（答案/xxx.md）/ 无官方答案，自行求解}
- **我的作答**：{用户给的答案或思路；未提供则写"未作答"}
- **正误**：{对 / 错 / 部分对 / 未判}
- **考点**：{知识点 1、知识点 2}
- **解答**：{分步推导，关键步骤带出处引用}
- **官方答案对照**：{有答案时逐点比对，指出与用户答案/自行解法的差异}
- **易错提醒**：{本题最容易踩的坑}
- **是否入错题本**：{是/否，错题本条目链接}
```

错题本条目追加到 `02-刷题记录/错题本.md`：

```markdown
### 错题 {编号}｜第NN章｜{考点}
- 记录日期：{YYYY-MM-DD}　掌握度：{不会/模糊/会做/熟练}
- 题目摘要：{一句话}　详录：{相对路径#题 1}
- 错误原因：{概念不清 / 公式记错 / 计算失误 / 审题偏差 / 方法不会}
- 正确关键：{一句话点破}
- 复习节点：D1={日期} D3={日期} D7={日期} D15={日期} D30={日期}
- 复习记录：{日期+结果，逐次追加}
```

## 6. 总结与复习规范

- **知识点总结**：按"概念 → 公式/结论 → 适用条件 → 与易混概念对比 → 典型例题链接"组织，每条带出处。
- **解题技巧**：按题型归类，写"识别特征 → 通用步骤 → 为什么这样做 → 一个真题链接"。
- **易错点**：写"错误表现 → 正确做法 → 触发场景"，只收录真正在刷题或讲解中暴露过的问题，不凭空罗列。
- **间隔复习**：新错题/新难点按 D1、D3、D7、D15、D30 排入 `复习计划.md`；每次学习开始时先列出"今天到期该复习"的条目。
- **掌握度更新**：复习后把错题掌握度上调或下调，连续两次"熟练"的条目可标记「已通关」，但保留记录不删除。

```markdown
# 学习档案
- 课程名称：
- 课程根目录：
- 教材与参考资料清单：
- 学习目标/考试时间：
- 当前学习章节：

## 章节进度
| 章节 | 资料已归档 | 已讲解 | 刷题数 | 错题数 | 掌握度 | 下次复习 |
|------|-----------|--------|--------|--------|--------|----------|

## 学习日志
| 日期 | 做了什么 | 产出文件 | 暴露的问题 | 下一步 |
|------|----------|----------|------------|--------|
```

每次学习会话结束前，必须更新 `学习档案.md` 的进度与学习日志。
